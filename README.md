# CyberTrace – Digital Evidence Analyzer

CyberTrace is a full-stack web application designed to support cyber-investigation and digital-forensics workflows by providing multiple tools for analyzing digital information and generating structured investigation reports.

The project was developed based on practical exposure to cyber-investigation and digital-forensics workflows during my internship at a Cyber Police Station.

## Features

### IP Analyzer
- Analyzes an IP address and retrieves:
  - Country
  - Region
  - City
  - ISP
  - Organization
  - Timezone
  - Latitude and Longitude

### Email Header Analyzer
- Extracts important information from raw email headers:
  - From
  - To
  - Subject
  - Date
- Identifies public IP addresses through which the email passed.
- Provides location and ISP information for identified IP addresses.
- Checks SPF and DKIM results.
- Generates a spoofing alert when authentication checks fail.

### CDR Parser
- Uploads and analyzes Call Detail Record (CDR) CSV files.
- Provides:
  - Total number of records
  - Top 5 callers
  - Call-frequency visualization
  - Contact network graph showing communication relationships

### URL Scanner
- Scans URLs using the VirusTotal API.
- Checks the URL against multiple security engines.
- Displays:
  - Malicious detections
  - Suspicious detections
  - Harmless results
  - Overall verdict

### Investigation Report Generator
- Generates downloadable PDF reports for analysis results.
- Reports include:
  - Timestamp
  - Analyst name
  - Station name
  - Findings and analysis results

## How It Works

CyberTrace provides separate analysis modules depending on the type of digital information being investigated.

```text
Digital Evidence
       │
       ├── IP Address ──────► IP Analyzer
       │
       ├── Email Header ────► Email Header Analyzer
       │
       ├── CDR File ────────► CDR Parser
       │
       └── URL ─────────────► URL Scanner
                                  │
                                  ▼
                         Structured Results
                                  │
                                  ▼
                         PDF Report Generator
```

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/Manya-trial/CyberTrace.git
cd CyberTrace
```

### 2. Install dependencies

```bash
pip install flask requests fpdf2 matplotlib networkx pandas
```

### 3. Run the application

```bash
python app.py
```

### 4. Open in your browser

```text
http://localhost:5000
```
